# CNP6S EC 协议记录

本文记录当前代码实际使用的协议，供审阅与维护参考，不是其他机型的通用写入指南。

| 操作 | 当前实现 |
| --- | --- |
| EC 数据端口 | `0x62` |
| EC 命令/状态端口 | `0x66` |
| 输入缓冲忙位 | `0x02` |
| 输出缓冲可读位 | `0x01` |
| 读取 EC 寄存器 | 发送命令 `0x80`，随后发送寄存器地址，读取一个字节 |
| 风扇数量 | EC 寄存器 `0xC8`，上层要求连续一致且在有效范围 |
| 读取温度/占空比 | 命令 `0x9E`，发送风扇编号，读取温度、一个忽略字节、占空比 |
| 设置占空比 | 命令 `0x99`，发送风扇编号、`round(percent * 255 / 100)` |
| 恢复自动 | 命令 `0x99`，发送 `0xFF`、风扇编号 |
| RPM 原始计数 | `0xD0 + 2*(fan-1)` 为高字节，下一个寄存器为低字节 |
| RPM 换算 | 原始计数为 0 时返回 0，否则 `round(2156220 / count)` |

风扇编号从 1 开始。底层端口操作集中在 `ec_probe.py`，带缓冲等待超时和有限重试；一致性检查与控制封装位于 `clevo_fan.py`。

GUI 使用工作线程串行访问 EC，进程间互斥量阻止本程序同时启动多个控制实例。互斥量不能阻止其他厂商控制软件访问 EC。

## GUI 策略

`fan_policy.py` 为每个风扇保存运行模式；曲线共享只共享温度到占空比的映射，每个风扇使用自己的温度。

曲线和手动模式在写入前读取受控通道温度；95°C 进入全速，降到 88°C 才解除。重新提交曲线或手动设置不会清除保护锁存。控制周期约 2 秒，监控周期约 1.5 秒，实际周期受 EC 读取耗时影响。

## 参考来源

- [PyECClevo](https://github.com/F-19-F/PyECClevo)：Clevo 命令布局及 RPM 换算参考。
- [InpOut32 / InpOutx64](https://www.highrez.co.uk/Downloads/InpOut32/)：Windows 端口访问 DLL 与内嵌驱动。

参考公开协议不表示上游项目验证或认可本机适配。第三方二进制与许可证见根目录 `THIRD_PARTY_NOTICES.md`。
